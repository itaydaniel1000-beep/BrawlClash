# שומר הודעות לווטסאפ

אפליקציית אנדרואיד ששומרת כל הודעה שמגיעה כהתראה מווטסאפ (רגיל ועסקי).
כשמישהו מוחק הודעה "אצל כולם", האפליקציה מקפיצה התראה עם הטקסט המקורי ושומרת אותו בלשונית "נמחקו".

## איך מקבלים את ה־APK
1. בגיטהאב, בלשונית **Actions**, פותחים את הריצה האחרונה של **WhatsApp Saver APK**.
2. בתחתית העמוד, תחת **Artifacts**, מורידים את `whatsapp-saver-apk` (קובץ zip שבתוכו `app-debug.apk`).
3. מעבירים לטלפון ומתקינים (צריך לאשר "התקנה ממקורות לא ידועים").

אפשר גם לפתוח את התיקייה ב־Android Studio וללחוץ Run.

## הפעלה ראשונה
1. פותחים את האפליקציה ולוחצים **אשר גישה להתראות**, ואז מסמנים את "שומר הודעות".
2. מאשרים קבלת התראות (באנדרואיד 13 ומעלה).
3. מומלץ: בהגדרות הסוללה מגדירים לאפליקציה "ללא הגבלה", כדי שהטלפון לא יכבה אותה ברקע (נפוץ בשיאומי, סמסונג ו־Huawei).

## מגבלות
- רק הודעות שהגיעו כהתראה נשמרות. צ'אט פתוח, צ'אט מושתק או התראות כבויות = אין מה לשמור.
- בעיקר טקסט. בתמונות או בהקלטות נשמר רק התיאור ("📷 תמונה").
- כל המידע נשאר בטלפון ושום דבר לא נשלח החוצה.
