Portal AI Agent Connector — התקנת התוסף (Chrome / Edge)
========================================================

התוסף הזה מאפשר לדף "סוכן AI" שבפורטל לזהות את הטאבים הפתוחים בדפדפן
ולעבור ביניהם. בלי התוסף אפשר עדיין להזין כתובת ידנית.

התקנה (חד-פעמית, במחשב עם Chrome או Edge):

1. הורד/שמור את התיקייה הזאת (agent-extension) למחשב.
   - אם הפרויקט אצלך על המחשב: התיקייה נמצאת ב-  portal/agent-extension
2. פתח בדפדפן את הכתובת:
      chrome://extensions      (ב-Edge:  edge://extensions )
3. הפעל למעלה-מימין את המתג "Developer mode" / "מצב מפתח".
4. לחץ על "Load unpacked" / "טען פריט לא ארוז".
5. בחר את התיקייה  agent-extension  (זו שמכילה את הקובץ manifest.json).
6. התוסף יופיע ברשימה. זהו!

בדיקה:
- פתח את דף הסוכן בפורטל. למעלה אמור להופיע "תוסף מחובר" (נקודה ירוקה),
  ובמסך "בחר טאב" יופיעו הטאבים הפתוחים שלך.

הערות:
- התוסף רק קורא כותרת/כתובת של טאבים ומאפשר מעבר אליהם. הוא לא שולח מידע לשום מקום.
- זמין רק ב-Chrome/Edge במחשב. באייפון/אנדרואיד אין תמיכה בתוספים כאלה.
- זה שלב 1 (זיהוי + מעבר). ביצוע המשימה האוטומטי (Gemini) יתווסף בשלב הבא.
