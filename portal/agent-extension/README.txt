Portal AI Agent Connector — התקנת התוסף (Chrome / Edge)
========================================================

התוסף מאפשר לדף "סוכן AI" שבפורטל:
  1) לזהות את הטאבים הפתוחים בדפדפן ולעבור אליהם.
  2) להריץ משימה אוטומטית על הטאב הנבחר (בעזרת Gemini) — קריאת הדף, החלטה, לחיצה/הקלדה, וחוזר חלילה.

התקנה (חד-פעמית, במחשב עם Chrome או Edge):
  1. שמור את התיקייה הזאת (agent-extension) למחשב.
     אם הפרויקט אצלך: portal/agent-extension
  2. פתח:  chrome://extensions    (ב-Edge:  edge://extensions )
  3. הפעל למעלה את "Developer mode" / "מצב מפתח".
  4. לחץ "Load unpacked" / "טען פריט לא ארוז".
  5. בחר את התיקייה agent-extension (זו עם manifest.json). זהו.

מפתח Gemini (חינם, חד-פעמי) — נדרש כדי שה-AI *יבצע* בפועל:
  1. היכנס ל-  https://aistudio.google.com/apikey
  2. צור מפתח (Create API key) — חינם.
  3. בדף הסוכן, במסך "מה ה-AI צריך לעשות?", פתח "⚙️ מפתח Gemini" והדבק אותו.
     המפתח נשמר רק במכשיר שלך (localStorage) ונשלח ישירות ל-Google.

בדיקה:
  - פתח את דף הסוכן. למעלה אמור להופיע "תוסף מחובר" (נקודה ירוקה) והטאבים יופיעו.
  - בחר טאב פתוח, כתוב מטרה, ולחץ "שלח". תראה לוג צעדים בזמן אמת.

בטיחות:
  - לפני פעולה בלתי-הפיכה (קנייה/תשלום/שליחת טופס/מחיקה) הסוכן עוצר ומבקש אישור בדף.
  - יש כפתור "עצור" שמפסיק מיד.

הרשאות (למה):
  - "tabs"         : לראות ולעבור בין טאבים.
  - "scripting" + "<all_urls>" : להזריק סקריפט קריאה/פעולה לטאב היעד כדי לבצע את המשימה.
  התוסף לא שולח נתונים לשום מקום מלבד קריאות ל-Gemini עם המפתח שלך.

מגבלות:
  - v1: עובד יפה על אתרים פשוטים; עלול להיתקל באתרים מורכבים / כניסות / CAPTCHA.
  - זמין רק ב-Chrome/Edge במחשב. אין תמיכה בתוספים באייפון/אנדרואיד.
  - שליטה בתוכנות מחוץ לדפדפן (משחקים) דורשת עוזר נייטיב — שלב נפרד בהמשך.
